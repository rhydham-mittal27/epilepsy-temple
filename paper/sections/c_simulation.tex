\subsection{Corrections to reported simulator outputs}

\begin{enumerate}
\item \textbf{\EGABA{} values.} The first values printed ($-70.7$, $-66$, $-57.7$, $-52$\,mV) came from a diagnostic that used the GHK form, not the chord form that the simulated current obeys. The recomputed chord values are $-69.6$, $-63.7$, $-54.1$ and $-48.3$\,mV. The dynamics were unaffected, and the code now records the chord form.
\item \textbf{Healthy silence metric.} It first printed 0.0\,s because the smoothing window still contained the trigger. The corrected metric searches from 1\,s after the trigger and gives 13.7\,s.
\item \textbf{Healthy discharge count.} The ``36 discharges'' in healthy tissue are threshold crossings by normal fluctuations, not epileptiform events; only rates should be compared.
\end{enumerate}

\subsection{Mapping onto seizure biology}

\paragraph{Reproduced.} The model reproduces:
\begin{itemize}
\item the ictal \Kp{} ceiling;
\item chloride loading and KCC2 loss;
\item KCC2-mediated \Kp{} loading;
\item interictal discharges;
\item \Nap{} accumulation and pump activation;
\item the adenosine surge;
\item postictal depression and the postictal \Kp{} undershoot;
\item ictal hyperperfusion followed by hypoperfusion;
\item spatial spread by lateral diffusion.
\end{itemize}

\paragraph{Not reproduced.} At the default pump setting the model does not produce a self-sustained 30--120\,s focal seizure. Loss of consciousness and motor signs are out of scope.

\paragraph{Scope.} Two further limitations define its scope:
\begin{itemize}
\item \textbf{Size and structure:} it is a 1-D network without dendrites, layers, thalamus or long-range connections.
\item \textbf{EEG readout:} it uses an LFP proxy rather than a volume-conductor EEG, and a simple threshold IED counter.
\end{itemize}
