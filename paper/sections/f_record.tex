A design decision between Studies 3 and 4 is worth recording. Asked which configuration would be most accurate, we concluded from Table~\ref{tab:generalft} that:
\begin{itemize}
\item the full cap with fine-tuning had the fewest false alarms (88/day);
\item the two-ear hook caught about as many seizures;
\item false alarms should be handled with additional signals (multimodal agreement, artefact sensors, tiered alerts, personal learning, risk forecasting) rather than more scalp electrodes.
\end{itemize}
This led to the body-signal review and the SeizeIT2 study.

\subsection{Operational incidents}

\begin{itemize}
\item \textbf{Memory-pressure reaping.} Long background jobs started from the assistant's session were repeatedly killed. Heavy jobs were therefore run in the author's terminal or as detached processes with log files and resumable checkpoints: results were saved as soon as each configuration finished, with per-configuration random seeds from a CRC32 of the configuration name.
\item \textbf{Sleep.} A stage-2 job paused for about 5 hours when the laptop entered Modern Standby. Scripts now call \code{SetThreadExecutionState} to prevent idle sleep.
\item \textbf{Network.} Three problems occurred:
\begin{itemize}
\item PhysioNet downloads ran at $\approx$153\,KB/s, so the AWS open-data mirror was used;
\item campus Wi-Fi gave 0.3--0.7\,MB/s per stream for the raw-EEG fetch;
\item 572 of 805 fetch attempts failed while a captive portal intercepted TLS (``self-signed certificate in certificate chain'') and DNS failed. Certificate verification was deliberately \emph{not} disabled; after the portal login the resumable stream continued.
\end{itemize}
\item \textbf{Disk.} With the drive nearly full, all large data were streamed and only features stored. A disk guard stops raw downloads below 1.5\,GB free.
\item \textbf{Files.} A PNG locked by an image viewer triggered a timestamped fallback file.
\item \textbf{Notifications.} Optional phone notifications (ntfy) announce completion, crashes or stopped processes.
\end{itemize}
