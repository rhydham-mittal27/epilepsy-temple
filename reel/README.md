# Epilepsy Temple: "The Detective Story" reel

`epilepsy_temple_reel.mp4`: 56 s, 1080×1920 (9:16), 30 fps, -14 LUFS. Ready for Instagram Reels, YouTube Shorts and TikTok.
`cover.jpg`: suggested cover frame (the 96% vs 91% verdict).

Cartoon animation, Kokoro TTS voiceover (`am_michael`), word-by-word captions, and synthesized music and SFX. Every frame is generated by code.

## Rebuild

```bash
# 0. Kokoro model (GitHub release of kokoro-onnx)
mkdir -p models && cd models
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
curl -LO https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
cd ..
pip install kokoro-onnx soundfile numpy        # + Node with Playwright, and ffmpeg

python voice.py          # narration -> build/voice.wav + build/timeline.json (word timings, mouth sync)
node render.mjs          # reel.html drawn frame by frame in headless Chromium -> build/frames.mp4
python mix.py            # music + SFX + ducking + loudnorm -> epilepsy_temple_reel.mp4
```

- Change the words: edit `SCRIPT` in `voice.py` (`*word*` = highlighted caption word). The visuals follow the timeline automatically.
- Change the voice: `REEL_VOICE=af_heart python voice.py` (any Kokoro voice); `REEL_SPEED=1.0` for slower.
- Live preview: `npx http-server .` then open `reel.html?preview`.
- Check frames: `node render.mjs --stills 5,20,40` writes PNGs to `build/`.

## Why it's built this way (short-form research)

| Practice | How the reel applies it |
|---|---|
| 65% drop off in the first 3 s, so hook with a question or curiosity gap | Opens on "2 sensors vs 18" + "Which one catches more seizures?"; characters are on screen from frame 0 |
| A visual change every 1.5–2 s | Every narration line triggers a pop, punch-in or new element; circle-wipe between scenes |
| Most people watch muted; animated word-by-word captions are the norm | Pop-in captions, highlighted active word, key words in yellow |
| Safe zones: keep clear of the top ~250 px and bottom ~450–670 px | Content sits between y≈300 and 1240; captions at y≈1335 |
| Story structure with open loops | Detective case: clue, plot twist, evidence, suspect, verdict, catch, "case not closed" |
| Watch time, completion and shares drive reach; stories run 30–60 s | 56 s with a cliffhanger CTA (Prototype 1) |
